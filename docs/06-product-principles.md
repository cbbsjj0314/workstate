# Product Principles

## Convenience Over Manual Completeness

WorkState must be easier than maintaining a plain note.

## Automatic Capture Before Manual Transcription

Observable workflow facts should be captured automatically where integrations
permit. Manual input is fallback and repair.

## Facts Before Inference

Observed facts and workflow interpretations are separate layers.

## Transparent Derivation

Derived workflow state must show evidence, provenance, confidence, and
interpretation status.

## Batch Confirmation

Uncertain interpretations should be confirmed at workflow boundaries or during
`resume`, not after every objective event.

## Local-First Storage

WorkState should keep workflow recovery data local-first by default.

## Manual Repair Always Available

The user must be able to add missing context, corrective information, or
overrides when capture is incomplete or wrong.

## Recommendations Are Optional

Recommendations may suggest next actions, but they are not objective facts and
do not replace user judgment.

## Plain Notes Are The Baseline

If WorkState is more burdensome than a plain note, rereading sessions, or
checking GitHub manually, the product has failed.
